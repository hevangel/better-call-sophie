# Google Flow — initial generation platform

**Start here if you're new:** [First Pilot Runs — step-by-step tutorial](tutorial-first-pilot.md) covers setup, three hands-on tests, prompts, credits, reference characters, dialogue, editing, and evaluation.

The human showrunner has a Google Flow subscription and intends to use it for early video generation. The pipeline must remain portable to other tools.

## Manual workflow

1. Approve the script/shot breakdown and continuity references.
2. Prepare prompt text, subject/reference image anchors, camera and action descriptions.
3. Use the currently available Flow interface to produce candidate shots; do not assume API automation.
4. Export usable shots (subject to current account/tool capabilities) into the designated production-storage folder.
5. Give each export a stable project shot ID; record the original filename, tool/model details when exposed, settings, prompt, and generation notes.
6. Review before marking a take `selected`; save output path to the shot record.

No Flow project links, generated clips, or model settings have been supplied yet. Never invent them.

Google's product details, models, policy and rights can change; verify live terms before claiming a particular resolution, duration, feature, entitlement or license. See `spec/production-pipeline.md`.
