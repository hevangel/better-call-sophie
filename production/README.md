# Production workspace

Text and lightweight records live in this directory. A local output directory (see `exports/`) is intentionally ignored by Git because generated video can be huge.

Start with an [episode treatment](../story/season-01/overview.md), create shot IDs, write prompts in `prompts/`, then log generation settings/results in `generation-logs/`. Follow [the production pipeline](../spec/production-pipeline.md).

No rendered episodes exist at project initialization.
