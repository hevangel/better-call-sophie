# Assets

Small, reviewable reference/marketing assets can be committed here. **High-res masters, source exports, animation and audio/video media belong in production storage** unless a deliberate Git LFS decision is made.

`marketing/` contains preview versions of the generated show poster and both sides of the fictional business card. Read the [asset manifest](../spec/asset-manifest.md) before revising.

Approved character and location reference packs should use `assets/characters/` and `assets/locations/`. In-world contact information printed on props is fictional; verify text before publishing.
